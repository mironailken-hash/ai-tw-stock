# AI 台股智慧分析（繁體中文版）

## 本機啟動
1. 安裝 Python 3.11+
2. 在此資料夾執行：
   pip install -r requirements.txt
3. 啟動：
   streamlit run app.py

## 部署成網頁
把 app.py 與 requirements.txt 上傳到 GitHub，
再到 Streamlit Community Cloud 建立 App，Main file path 選 app.py。

## 資料
第一版使用 FinMind API。建議註冊並取得 Token，在網頁左側輸入。

## 注意
本程式提供市場資訊整理與技術分析研究，不保證未來價格或投資結果。
